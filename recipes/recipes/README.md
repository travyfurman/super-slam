# Odin recipes
A html page with a landing page and links to three delicious recipes. This is the first project in the Foundations course on The Odin Project.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- VSCode or an IDE of your preference


### Installation

1.  Clone the repository:
    ```sh
    git clone https://github.com/travyfurman/super-slam.git
    ```
2.  Open the project in VSCode.
